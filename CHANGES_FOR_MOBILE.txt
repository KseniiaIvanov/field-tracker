6. DEPLOYMENT STEPS
================================================================================

Quick Deploy (PWA):

  Step 1: Generate Icons
    → Follow ICON_GENERATION.md

  Step 2: Build App
    $ npm run build

  Step 3: Deploy (choose one)

    Option A - Vercel (RECOMMENDED):
      $ npm i -g vercel
      $ vercel
      # Done! HTTPS enabled automatically

    Option B - Netlify:
      $ npm run build
      $ netlify deploy --prod --dir dist

    Option C - Your Server:
      $ npm run build
      $ scp -r dist/* user@yourdomain.com:/var/www/

  Step 4: Test
    • Visit site on iPhone (Safari)
    • Visit site on Android (Chrome)
    • Tap install button/menu option
    • Verify app appears on home screen

Optional Native Apps:
  → See MOBILE_SETUP.md for Capacitor setup
  → Creates iOS and Android native app wrappers
